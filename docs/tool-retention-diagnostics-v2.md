# 工具结果残留口径

工具结果残留和请求总输入都从同一个 DSH 请求边界估算。匹配同轮同请求的首个流式回包事件。历史日志只保存最终回复时，使用写入回复之前的可见上下文。该重建基于宿主日志，提供商侧重写和精确分项 Token 尚不可观察。

按 surface 操作维护可见消息。替换、压缩和裁剪移除被替换范围，只有进入消息面的结果参与统计。同轮同一次工具调用的重复结果取最后可见记录。工具结果、其他消息和已记录的请求封装共用 DSH 的内容块和消息结构估算。模型实报输入独立展示。

跨轮重复携带逐次请求用同一对估算分子、分母配对。超出 100% 或出现内部不一致的记录标记异常，依赖该数据的 T + E、A/B/C、历史趋势与回测会跳过相应无效读数。日志无法重建时显示缺失。原始 U、A、K、E 继续使用既有统计。

缺少可见请求消息或入面记录不完整时，T 未知，模型实报用量继续保留。可重建的请求明确没有工具结果时，残留为零。

当前口径标识为 `diagnostics-v3`，分析检查点为 v10。旧检查点按原始日志重建，新轮末快照另写入 `pressure-v0.3`。已有 `diagnostics-v2` 快照原样保留。历史比较、回测及归因使用新口径，公式版本和参数保持原值。

`logs/session-pressure/samples.json` 保存现场轮末采样和压缩前后配对读数，路径沿用。手动及自动备份纳入该文件。恢复时合并新旧观测，共用事件键保留本机读数，恢复前原件仍在隔离目录。
