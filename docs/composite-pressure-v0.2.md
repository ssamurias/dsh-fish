# 会话压力 · 同轮统计与走势 v0.2

页面入口已在 [v0.3](session-pressure-ui-v0.3.md) 重组。此页保留 v0.2 的计算与缓存背景。

[历史预测回测 v0.1](pressure-backtest-v0.1.md) 使用同一份逐轮诊断评估三种外推方法。

在「记忆 → 会话压力 → 计算」顶部查看 A/B/C 实时分数。展开下面的公式卡片可以独立调参并重置。三种综合公式、七项原始指标和三个子模块沿用 [v0.1 的口径](composite-pressure-v0.1.md)。

「压力走势与多 Session 对比」默认折叠。展开后会加载当前 Session，可看 A、B、C 或三条同时显示，可选全部轮次及最近 10、20、50 轮。移动指针或拖动轮次控件查看分数、实际历史样本数及压缩事件。多 Session 模式最多选择 5 个会话并共用一个公式，历史候选来自「历史」页已选中的会话。

历史同轮统计默认查看当前 Session 最新的成功用户轮。用表格滑块或点击图表选择一个轮次。历史候选只需在该轮具有可重算的数据，A/B/C 分别统计各自有效样本。默认允许混合模型与窗口，跨配置结果会提示尚未校准。「仅同配置」核对所选轮最后一次实报请求的提供商、模型和窗口。诊断版本与公式版本仍须一致。百分位使用中秩，样本数为 0、1–4、5–19 时分别显示暂无样本、样本极少和样本有限。中位数虚线逐轮独立统计。

## 数据与缓存

- 后端从现有 Session 事件与轮末 meter 统计读取数据。每个点截止于对应的成功用户轮结束事件。按轮递进复用诊断检查点，请求、工具和压缩事件沿用现有分析器，切换配置后保留累计用量。历史增长优先使用相邻两轮的 meter 占用率，任一轮缺 meter 样本时改用该对轮各自最后一次请求的实报输入占用率，并记录此类轮对的数量。跨窗口使用各轮真实窗口计算占用率，再取差值，图表标出窗口变更。该差值包含窗口变化的影响。所需实报数据缺失时保留断点。
- 趋势请求按需从本机 API 加载。缓存保留最近 16 个会话的诊断序列，以会话更新与采样变化为失效条件。每处理 8 轮让出执行，沿用每会话 20,000 事件的既有分析边界。轮末紧凑快照继续写入本地缓存，含诊断版本、来源指纹、模型与窗口、输入和完整性。完整聊天及工具原文继续由宿主保存。
- 浏览器持有可重算的诊断输入。子模块系数会更新依赖它的所有方案。A/B/C 的参数各自影响其对应曲线与统计。子模块的人工情景输入作用于实时试算，走势仍使用轮末实测输入。
- 模型、窗口切换及压缩、裁剪标记来自日志。图表详情显示当轮配置与切换状态。压缩 Token 变化只在有同次压缩配对采样时显示。
