## 变化归因

在「历史 → 变化归因」选择会话、起止轮和 A/B/C。三项子压力与综合分使用当前实验参数。A 直接把各子项分差乘归一化权重。B/C 对三个子压力的六种替换顺序取平均边际贡献，即 Shapley 分解。贡献以完整精度求和，与综合分变化一致，显示值分别保留一位小数。数学贡献描述评分公式中的变化。

从回测明细的一条目标预测进入归因，会带入会话、起点、目标轮、公式和预测方法。误差贡献以目标轮实际子压力为起点、该次预测子压力为终点。预测仍只读起点及以前的数据。两组贡献分别描述区间变化与预测误差。

## 数据与边界

工具结果残留使用 [同请求、同估算口径](tool-retention-diagnostics-v2.md)。模型实报输入单独展示。

逐轮历史继续读取原日志前缀与既有轮末采样。只有归因请求需要传送七项端点诊断的统计字段，响应包含单位、来源、范围以及已记录的事件元数据。压缩 Token 变化依赖成对采样。缺失轮次保留断点，端点诊断缺失时会提示。工具和轮次列表使用现有有界样本，逐轮用量补充最近 200 个已分析记录。既有原日志、缓存和旧版后端统计接口继续保留。

安装后可在现有历史 Session 上用同一套参数复核端点、事件与数学贡献。
