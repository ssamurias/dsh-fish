# 首页容量建议 v0.1

「记忆 → 会话压力 → 当前」先显示一条建议和最多三项依据。A/B/C 评分、容量预览、近期走势、三个子压力和诊断摘要在下方。可以展开具体依据，或进入历史同轮次、完整走势、诊断和计算页面。

规则按表中顺序执行。

| 条件 | 状态 |
| --- | --- |
| 当前窗口或输入缺失 | 数据不足，暂不能判断 |
| 当前占用 ≥95% | 强烈建议切换 |
| 当前占用 ≥85%，或预计 5 轮后 ≥95% | 建议准备新会话 |
| 当前占用 ≥70%，或预计 10 轮后 ≥85% | 继续使用，留意变化 |
| 其他有实际占用读数的情况 | 继续使用 |

建议读取最近一笔实报请求的输入和有效窗口。预测复用 C+G 的可比轮末增长与现行容量推演，固定使用 5、10 轮，展示值限制在 0–100%。缺少增长时保留当前容量判断，预测显示未知。近期压缩、裁剪或配置切换会提示走势可能不稳定。最高级别只由实际占用触发。

阈值为未校准的实验规则。A/B/C 和情景参数继续联动原评分展示，工具残留估算用于解释占用来源。首页按钮仅跳转分析视图。规则本地执行。
