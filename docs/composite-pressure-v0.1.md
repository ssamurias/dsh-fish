# 综合压力 · 三方案对比 v0.1

打开「记忆 → 会话压力 → 计算」。前三张卡片仍提供容量、请求与结构的独立读数。第四张卡片从同一份诊断响应取得三个子分，打开计算页时每五秒刷新。请求使用该卡片的缓存缺报保守上界。

| 方案 | 默认参数 | 计算 |
| --- | --- | --- |
| A · 分层加权 | 容量 0.50、请求 0.30、结构 0.20 | 三个子分的归一化加权平均。总权重为零时显示 —。 |
| B · 非线性合成 | 容量 0.50、请求 0.30、结构 0.20 | 从 1 减去各维度剩余因子的乘积。强度独立生效，全部为零时得 0 分。 |
| C · 容量主导修正 | 请求 0.60、结构 0.40、μ 0.35 | 在容量分基础上，按剩余空间、μ 和请求／结构加权平均增加修正。 |

展开各方案的「公式与计算明细」查看贡献、因子和修正。每张卡片的默认值可单独恢复。试算用于比较公式敏感性。

## 历史同轮次

在「历史」标签勾选参与比较的会话。计算页按当前成功完成的用户轮数 N，回放每个已选会话至其第 N 个成功轮末。参考组要求相同模型提供商、模型和窗口大小，且会话前缀中的成功请求使用同一配置。实时读数已进入下一轮或使用子模块情景覆盖时，等待轮末或恢复实时输入后再比较。

增长数据需要可核对的历史轮末 meter 采样。缺轮、缺诊断字段、配置混用和分析尚未完成都会减少样本数。改动子模块评分系数或 A/B/C 参数会立即用各会话的诊断输入重算。百分位按「低于当前的样本数 + 相同分数样本数的一半」除以有效样本数。少于 10 个可比会话会显示提示。

## 快照与维护

打开计算页并取得轮末诊断时，在插件数据目录的 `session-pressure-cache/pressure-v0.1/<Session ID>/<N>.json` 写入一份可重算快照。快照包含采样时间、模型和窗口、诊断量、子分、综合分、对应的默认参数和三个子分的完整性标记。界面调参用于当前页面试算。需要的历史原始量由本机日志前缀和已有轮末采样重建。

版本为 `capacity_v0.1`、`request_v0.1`、`structure_v0.1`、`composite_v0.1`。修改公式后运行 `node scripts/sync-pressure-formulas.mjs` 同步浏览器脚本，再运行 `node scripts/sync-pressure-formulas.mjs --check`。
